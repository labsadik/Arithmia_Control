# Arithmia Control

### AI Operations & Intelligence Control Center

**Arithmia Control** is a unified command center for modern AI infrastructure. It brings AI models, LLMs, agents, pipelines, infrastructure, databases, customers, usage, costs, and operational intelligence into a single real-time interface.

Built for teams that need **visibility, control, and intelligence across their entire AI operation.**

---

## Overview

As AI systems become more complex, organizations increasingly operate across multiple models, agents, APIs, databases, servers, and customer-facing applications.

Arithmia Control is designed to provide a centralized operational layer across these systems.

Instead of switching between disconnected tools, teams can use one interface to understand:

* AI model and LLM activity
* Agent operations
* Infrastructure health
* Server and database status
* AI usage and costs
* Customers and companies
* Leads and activity
* Notifications and operational events
* Real-time system intelligence
* Market and business signals

### One platform. One operational view.

# Architecture

Arithmia is built around a connected operational model:

```text
                    ARITHMIA CONTROL
                           │
          ┌────────────────┼────────────────┐
          │                │                │
       AI / LLMs        AI Agents       Infrastructure
          │                │                │
          └────────────────┼────────────────┘
                           │
                    Operational Data
                           │
             ┌─────────────┼─────────────┐
             │             │             │
          Users        Customers      Databases
             │             │             │
             └─────────────┼─────────────┘
                           │
                    Intelligence Layer
                           │
                     CONTROL CENTER
```

The objective is to create a single operational view rather than another disconnected monitoring tool.

# Getting Started

### Requirements

* Node.js
* npm
* Supabase project

### Installation

```bash
git clone YOUR_REPOSITORY_URL
cd arithmia
npm install
```

### Environment

Create a `.env` file with your Supabase configuration:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
